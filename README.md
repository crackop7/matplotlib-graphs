# matplotlib-graphs

A Python mini project that plots different types of graphs using the Matplotlib library.

## Graphs included

Line, bar, horizontal bar, stacked bar, histogram, scatter, pie, box, violin, area, step, stem, error bar, and heatmap.

## Requirements

- Python 3.8+
- matplotlib
- numpy

```bash
pip install matplotlib numpy
```

## Usage

```bash
python matplotlib_graphs.py
```

This opens a window with all the graphs and also saves them as `matplotlib_graphs.png`.
